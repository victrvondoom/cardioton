# Utilities

This directory contains utility scripts and helper files for MedRelay.

## Files

- `hophacks__utilities__demo.py` - Demo script showing how to use the MedRelay API
- `hophacks__utilities__run.py` - Alternative run script (use `hophacks__main.py` in root directory instead)
- `setup.py` - Setup script for installing dependencies
- `test_app.py` - Test script for the application
- `pdf_generator.py` - Legacy PDF generator (not used in current version)

## Usage

Most of these are utility scripts. The main application entry point is `hophacks__main.py` in the root directory.
