5-Fold Stratified Cross-Validation Benchmark

Dataset: UCI Z-Alizadeh Sani Coronary Artery Disease Cohort (303 patients, 54 features).

Target Leakage Policy: Cath, CAD, LAD, LCX, and RCA are strictly excluded from input feature spaces.

Methodological Highlights:
  • Stratified 5-Fold Cross-Validation ensures robust out-of-fold generalization.
  • Class imbalance addressed via positive class weighting (scale_pos_weight) and balanced tree priors.
  • Calibrated probabilities verified with Brier Score & PR-AUC analysis.
